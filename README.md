# you-owe-me-15

## Node.js

Developed with Node.js v24.15.0.

## Install

```sh
npm install
cd src/frontend && npm install
```

## Development

Terminal 1: run Express on http://localhost:3000.

```sh
npm run dev:backend
```

Terminal 2: rebuild Angular on change.

```sh
npm run dev:frontend
```

## Production

```sh
npm run build
npm start
```
